# **App Name**: Personal Showcase

## Core Features:

- Dynamic Profile: Display the personal details, contact information, and professional summary from the user's data.
- Experience Timeline: Showcase the work experience in a chronological order with details fetched dynamically.
- Technology Showcase: Display known technologies, using icons, dynamically.
- Contact Links: Display icons that are actual links, opening in a new tab.
- Firebase Initialization: Include the firebase config variables so the user can start with a pre-configured Firebase app.

## Style Guidelines:

- Primary color: Light violet (#D8CEF6) to maintain the theme as requested.
- Background color: Very light violet (#F4F0FF), almost white, providing a clean backdrop.
- Accent color: A slightly darker shade of violet (#B19CD9) to highlight interactive elements.
- Font pairing: 'Poppins' (sans-serif) for headers, providing a modern and fashionable look; 'PT Sans' (sans-serif) for body text, which ensures readability.
- Use modern, outline-style icons to represent different sections (work experience, skills, contact). Match the icons with the light violet theme.
- Use Bootstrap's grid system for a responsive layout, ensuring compatibility across devices. The design should be modular, using prop-driven components for experiences and technologies.
- Subtle transition animations for section reveals and content updates to provide a smooth user experience.
